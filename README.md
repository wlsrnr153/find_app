# 📦 물품 조사 시스템

스마트폰과 PC에서 사용 가능한 실시간 물품 조사 웹 애플리케이션입니다.

## ✨ 주요 기능

### 📱 모바일 최적화
- 스마트폰에서 편리한 물품 정보 입력
- 반응형 디자인으로 모든 기기 지원
- 터치 친화적인 인터페이스

### 📝 물품 관리
- 물품명, 제조사, 모델명, 치수 등 상세 정보 입력
- 카테고리별 분류 (가구, 전자제품, 사무용품 등)
- 실시간 검색 및 필터링

### 👥 다중 사용자 지원
- 여러 명이 동시에 조사 가능
- 조사자별 데이터 관리
- 조사자 이름 자동 저장

### 📊 데이터 관리
- **엑셀 내보내기**: 조사 데이터를 엑셀 파일로 다운로드
- **JSON 내보내기**: JSON 형식으로 백업
- **데이터 가져오기**: 엑셀/JSON 파일 업로드
- 데이터 수정 및 삭제

## 🚀 설치 및 실행

### 필요 사항
- Node.js (v14 이상)
- npm

### 1단계: 의존성 설치

```bash
npm install
```

### 2단계: 서버 실행

```bash
npm start
```

개발 모드 (자동 재시작):
```bash
npm run dev
```

### 3단계: 웹 브라우저에서 접속

```
http://localhost:3000
```

## 📱 스마트폰에서 접속하기

### 같은 Wi-Fi 네트워크에 연결된 경우

1. PC의 IP 주소 확인:
   - Windows: `ipconfig` 명령 실행
   - Mac/Linux: `ifconfig` 또는 `ip addr` 명령 실행

2. 스마트폰 브라우저에서 접속:
   ```
   http://[PC의IP주소]:3000
   ```
   예: `http://192.168.0.100:3000`

### 외부 네트워크에서 접속 (선택사항)

포트 포워딩 또는 ngrok 등의 터널링 서비스를 사용하여 외부 접속 가능합니다.

## 📖 사용 방법

### 물품 입력
1. **📝 입력** 탭 선택
2. 조사자 이름과 물품 정보 입력
3. **✅ 저장** 버튼 클릭

### 물품 조회
1. **📋 목록** 탭 선택
2. 검색창으로 물품 검색
3. 카테고리 필터 사용 가능

### 데이터 내보내기
1. **⚙️ 관리** 탭 선택
2. **📊 엑셀로 다운로드** 버튼 클릭
3. 다운로드된 파일을 PC나 클라우드에 저장

### 데이터 가져오기
1. **⚙️ 관리** 탭 선택
2. **📂 파일 선택** 버튼 클릭
3. 이전에 내보낸 엑셀/JSON 파일 선택

## 📂 프로젝트 구조

```
find app/
├── server.js           # 백엔드 서버 (Express)
├── package.json        # 프로젝트 설정
├── data/              # 데이터 저장 폴더
│   └── items.json     # 물품 데이터 (자동 생성)
├── uploads/           # 업로드 임시 폴더 (자동 생성)
└── public/            # 프론트엔드 파일
    ├── index.html     # 메인 HTML
    ├── style.css      # 스타일시트
    └── app.js         # 클라이언트 JavaScript
```

## 🔧 설정

### 포트 변경
`server.js` 파일에서 포트 번호 변경 가능:
```javascript
const PORT = 3000; // 원하는 포트로 변경
```

### 데이터 백업
`data/items.json` 파일을 정기적으로 백업하는 것을 권장합니다.

## 💡 팁

1. **조사자 이름 자동 완성**: 한 번 입력한 조사자 이름은 자동으로 저장됩니다.
2. **빠른 입력**: 필수 항목(*표시)만 입력하고 저장 가능합니다.
3. **데이터 백업**: 정기적으로 엑셀 다운로드로 백업하세요.
4. **검색 기능**: 목록 탭에서 물품명, 조사자명, 제조사 등으로 검색 가능합니다.

## 🛠️ 기술 스택

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Backend**: Node.js, Express
- **데이터**: JSON 파일 기반 (간단하고 이식성 좋음)
- **엑셀 처리**: SheetJS (xlsx)
- **파일 업로드**: Multer
